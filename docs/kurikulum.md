# 🎼 Kurikulum Piano 30 Hari — Rangka Modul

**Pendekatan:** Chord-first. Pelajar faham *chord structure* & *chord progression* awal supaya boleh main lagu kegemaran tanpa perlu baca not staf. Setiap hari ada: matlamat, pelajaran pendek, widget interaktif, dan latihan 15–30 minit.

**Prinsip:**
1. Satu konsep kecil setiap hari — tidak membebankan.
2. Setiap hari ada elemen praktikal (tangan di kekunci).
3. Semua widget interaktif: keyboard menyala, bunyi sebenar, progression player.
4. Ujian ringkas di hujung minggu (H7, H14, H21, H30).

## Widget interaktif (direkod di data.js)
- `freeplay` — keyboard penuh boleh klik/tap
- `chord` — highlight + main satu chord (nama, notes)
- `scale` — main skala naik/turun, kekunci menyala berurutan
- `prog` — chord progression + pattern iringan (block/8beat/waltz/arpeggio)
- `song` — lagu melodi, kekunci menyala ikut masa (falling-highlight)
- `metro` — metronome BPM
- `demo` — demo konsep (legato/staccato/dynamics) — variasi chord/song player
- `check` — checklist kemahiran
